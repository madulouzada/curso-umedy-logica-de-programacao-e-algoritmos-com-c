# 📘 Lógica de Programação e Algoritmos com C 

Este repositório reúne os estudos, exercícios e projetos desenvolvidos durante o curso  
**Lógica de Programação e Algoritmos com C**, realizado na plataforma **Udemy**.

O conteúdo aborda desde os fundamentos da lógica de programação até conceitos intermediários e avançados da linguagem C, com foco em boas práticas, estruturação de código e resolução de problemas. Em cada seção, há exercícios para reforçar o entendimento do conteúdo.
